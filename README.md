An entry for the make.fun bounty
[One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

`main.ts` writes the entrant's own make.fun username — one word, nothing
else — to `/output/entry.txt`. The entry is exactly `mioand` (6 characters,
a single word), which the judge compares two at a time against other
entrants' usernames.

Run it with Node 22.18 or later:

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
